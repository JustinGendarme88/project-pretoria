# Project Pretoria

Narrative top-down RPG prototype built with Godot 4.

## Overview

Project Pretoria is a 2D RPG prototype focused on narrative systems, branching dialogue, NPC interaction, and scalable gameplay architecture.

The project is designed as a technical portfolio piece showcasing gameplay scripting, state management, data-driven resources, and UI systems in Godot.

## Features

- Ink-based branching dialogue system
- NPC interaction system with interaction prompts
- Data-driven NPC configuration using Godot Resources
- NPC reputation system
- Player state management
- Dynamic dialogue portraits using Ink tags
- Global flag system for story progression
- Dialogue choices and conditional narrative logic
- Scalable architecture for future RPG systems

## Tech Stack

- Godot 4
- GDScript
- Ink / InkGD
- Git / GitHub

## Current Status

This project is currently in active development.

Implemented systems include:
- DialogueManager
- DialogueUI
- NPCData resources
- ReputationManager
- FlagManager
- PlayerState
- InteractionPrompt

## Goal

The goal is to build a small but expandable narrative RPG prototype with clean systems that can evolve into a larger RPG project.
